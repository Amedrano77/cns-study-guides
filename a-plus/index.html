1.3 Mobile Device Security

  • MDM (Mobile Device Management): Corporate software to manage, monitor, wipe devices remotely
  • Remote Wipe: Erase all data from a lost/stolen device
  • Screen Lock: PIN, pattern, fingerprint, face unlock
  • Full Device Encryption: Default on modern iOS and Android
  • Locator apps: Find My (Apple), Find My Device (Android)
  • MicroSD: External storage — can also store malware; disable if policy requires
Rooting vs Jailbreaking: Rooting = Android (gaining root/superuser access). Jailbreaking = iOS (bypassing Apple restrictions). Both void warranties, remove security protections, and violate most corporate MDM policies. If a user's phone is rooted, treat it as untrusted.

3. Hardware & Components Core 1 — 1101

3.1 CPU Concepts

  • Cores: Physical processing units — more cores = better multitasking
  • Threads: Logical processors — hyperthreading doubles thread count per core
  • Cache: L1 (fastest/smallest) → L2 → L3 (slowest/largest) — stores frequently used data
  • Socket types: Intel LGA (pins on motherboard), AMD AM5 (pins on CPU)
  • TDP: Thermal Design Power — how much heat the CPU produces; determines cooler needed
  • Overclocking: Running CPU faster than rated speed — requires better cooling, voids warranty

3.2 RAM

TypeForm FactorUseKey Detail
DDR4DIMM / SO-DIMMDesktop / LaptopCurrent standard — 2133–3200 MHz
DDR5DIMM / SO-DIMMDesktop / LaptopNewer — faster, higher capacity

🧠 RAM is NOT permanent storage. It loses everything when power is cut. That's why you save files to disk — RAM is just your workspace.

3.5 Power Supply (PSU)

  • Wattage: Match to system needs — GPU-heavy systems need 750W+
  • 80 PLUS Rating: Efficiency certification: Standard → Bronze → Silver → Gold → Platinum → Titanium
  • Modular vs Non-modular: Modular = only connect cables you need (cleaner builds)
  • Connectors: 24-pin ATX (motherboard), 8-pin EPS (CPU), PCIe 6/8-pin (GPU), SATA power, Molex
  • Voltage rails: +3.3V, +5V, +12V (most important — powers CPU/GPU)
POST Beep Codes: If a system won't boot and beeps, count the beeps — they're error codes. 1 beep = usually OK. Multiple beeps = RAM, GPU, or CPU issue depending on BIOS manufacturer. No beep at all = likely dead PSU, CPU, or motherboard.

5. Hardware & Network Troubleshooting Core 1 — 1101

5.1 Troubleshooting Methodology (CompTIA Official Steps)

  1. Identify the problem — Question the user, review logs, duplicate issue if possible
  2. Establish a theory of probable cause — Start simple (Is it plugged in? Is the service running?)
  3. Test the theory — If confirmed, move to fix. If not, establish new theory.
  4. Establish a plan of action — Know your fix. Consider side effects before acting.
  5. Implement the solution or escalate — Fix it or pass to the right person.
  6. Verify full system functionality — Test beyond just the reported issue.
  7. Document findings, actions, and outcomes — Future you (and your team) will thank you.

5.2 Common Hardware Issues

Overheating / shutdownsDust buildup, bad thermal paste, failed fanClean with compressed air, replace thermal paste

5.3 Network Troubleshooting Steps

# Step 1 — Can you ping yourself?
ping 127.0.0.1          # Tests local TCP/IP stack

# Step 2 — Do you have an IP?
ipconfig /all           # Check for valid IP (not 169.254.x.x)

# Step 3 — Can you reach your gateway?
ping 192.168.1.1        # Replace with your default gateway

# Step 4 — Can you reach the internet by IP?
ping 8.8.8.8            # Google DNS — bypasses DNS resolution

# Step 5 — Can you resolve DNS?
ping google.com         # If this works but step 4 fails — routing issue
nslookup google.com     # If this fails — DNS issue

# Step 6 — Trace the path
tracert google.com      # See where packets stop

7. Security Fundamentals Core 2 — 1102

7.1 Malware Removal Process

  1. Investigate and verify — Confirm it's actually malware, not a false positive
  2. Quarantine the infected system — Disconnect from network to prevent spread
  3. Disable System Restore — Prevents malware from hiding in restore points
  4. Boot into Safe Mode — Minimal drivers, harder for malware to run
  5. Run malware scans — Use multiple tools (Malwarebytes, Windows Defender)
  6. Remove all infections — Follow tool recommendations, manual removal if needed
  7. Re-enable System Restore and create restore point
  8. Patch and update everything — Close the vulnerability that allowed infection
  9. Educate the user — How did this happen? Don't let it happen again.

7.2 Windows Security Features

7.3 Common Threats

ThreatDescriptionDefense
PhishingFake email/site to steal credentialsUser training, email filtering, MFA
RansomwareEncrypts files, demands paymentBackups, AV, patch management
KeyloggerRecords keystrokes to steal passwordsAV, virtual keyboards for sensitive input
Man-in-the-MiddleIntercepts communicationsHTTPS, VPN, certificate validation

Principle of Least Privilege: Every user, app, and service should have the minimum access needed to do their job — nothing more. An accountant doesn't need admin rights. A web server process shouldn't run as root. This single principle limits the damage of ANY compromise.

8.3 Application Issues

  • App won't install: Check permissions (run as admin), .NET version, 32-bit vs 64-bit compatibility
  • App crashes on launch: Check Event Viewer → Application log for error codes
  • Slow application: Check RAM usage in Task Manager, disk I/O, background processes
  • App not responding: Task Manager → End Task. Check for updates or reinstall.
  • Missing DLL error: Reinstall the application or install the required runtime (Visual C++, .NET)
  • Profile issues: Create new user profile — old profile may be corrupted

9. Operational Procedures Core 2 — 1102

9.1 Documentation Best Practices

  • Network diagrams: Physical (cables, devices) and logical (IPs, VLANs, subnets)
  • Asset inventory: Every device — serial number, location, owner, software installed
  • Change management: Document every change BEFORE making it — who approved it, rollback plan
  • Knowledge base: Solutions to recurring problems — saves time for everyone
  • Standard operating procedures (SOPs): Step-by-step processes for common tasks
  • Incident reports: What happened, when, impact, resolution, prevention

9.2 Change Management

ImplementationMake the change during approved maintenance window
Rollback planIf it breaks — what exactly do you do to undo it?

9.3 Backup Types

TypeWhat It Backs UpRestore TimeStorage Used
FullEverything — every fileFastest restoreMost storage
IncrementalChanges since last backup (any type)Slowest restore (need full + all incrementals)Least storage
DifferentialChanges since last FULL backupFast restore (full + latest differential)Medium storage

3-2-1 Backup Rule: Keep 3 copies of data, on 2 different media types, with 1 copy stored off-site. If ransomware hits and your only backup is on the same network — you have no backup.

11.2 Laser Printer Process (MUST KNOW — In Order)

  1. Processing — Data sent to printer, RIP creates bitmap of page
  2. Charging — Corona wire/charge roller applies uniform negative charge to drum
  3. Exposing — Laser writes image onto drum — exposed areas lose charge
  4. Developing — Negatively charged toner sticks to laser-exposed (positive) areas
  5. Transferring — Transfer belt/roller moves toner from drum to paper
  6. Fusing — Fuser unit (heat + pressure) permanently bonds toner to paper
  7. Cleaning — Blade removes remaining toner from drum, ready for next page

🖨️ Memory trick: "People Can Expect Dedicated Technicians For Customers" — Processing, Charging, Exposing, Developing, Transferring, Fusing, Cleaning

12.2 ESD (Electrostatic Discharge) Safety

  • Anti-static wrist strap: Ground yourself before touching components — wear it every time
  • Anti-static mat: Work surface that dissipates static charges
  • Anti-static bags: Store components in these — never on foam or carpet
  • Touch the case: If no strap, touch unpainted metal on case to discharge before touching components
  • Never blow air from your mouth: Moisture damages components — use canned/compressed air only

12.3 Safety Procedures

  • Disconnect power before servicing: Always unplug — even "off" PSUs have standby voltage
  • CRT monitors: Capacitors hold thousands of volts even when unplugged — never open
  • MSDS/SDS sheets: Material Safety Data Sheets — required documentation for chemicals (toner, batteries)
  • Lifting technique: Bend knees, not back — servers are heavy
  • Fire extinguisher types: Class C for electrical fires (CO₂ or dry chemical — NEVER water)

12.4 Environmental Controls

Proper disposal matters: Batteries, toner cartridges, CRT monitors, and circuit boards contain hazardous materials. Never throw them in regular trash. Follow your local e-waste regulations. On the exam — always choose the environmentally responsible disposal option.
