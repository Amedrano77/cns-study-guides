3. Navigating and Managing the Command Line

Essential Navigation

pwd                    # Where am I?
ls -la                 # List all files with details
cd /etc                # Go to /etc
cd ..                  # Go up one level
cd ~                   # Go home
cd -                   # Go to previous directory

File Operations

touch file.txt         # Create empty file
mkdir newdir           # Create directory
mkdir -p a/b/c         # Create parent directories too

cp source dest         # Copy file
cp -r sourcedir destdir # Copy directory

mv oldname newname     # Rename or move
rm file.txt            # Remove file
rm -rf directory/      # 🔥 DANGER: recursive force remove

ln -s target link      # Create symbolic link (shortcut)

💡 Pro tip: Always double‑check before rm -rf. I've seen whole servers wiped by a stray space. Use ls first!

Viewing Files

cat file.txt           # Show entire file (short)
less file.txt          # Page through (q to quit)
head -n 20 file.txt    # First 20 lines
tail -f /var/log/syslog # FOLLOW logs in real‑time — ESSENTIAL

Getting Help

man command            # THE manual — learn this first
command --help         # Quick summary
info command           # Alternative docs

5. Users, Groups, and Permissions

Key Files

FilePurposeExample
/etc/passwdUser accountsjoe:x:1001:1001:Joe:/home/joe:/bin/bash
/etc/shadowHashed passwordsroot‑readable only
/etc/groupGroup definitionsdevelopers:x:1002:alice,bob

User/Group Commands

sudo useradd -m -G wheel alice     # Create user with home, add to wheel
sudo passwd alice                   # Set password
sudo usermod -aG docker alice       # Add to supplementary group
sudo userdel -r alice               # Delete user AND home dir

sudo groupadd developers             # Create group
sudo groupdel developers             # Delete group

id alice                             # Show UID, GID, groups

Understanding Permissions

ls -l shows: -rwxr-xr--

  • Position 1: file type (- file, d directory, l link)
  • Pos 2‑4: owner permissions (rwx)
  • Pos 5‑7: group permissions (r-x)
  • Pos 8‑10: others permissions (r--)

Numeric (Octal) Permissions

r = 4, w = 2, x = 1
Common: 7 (rwx), 6 (rw-), 5 (r-x), 4 (r--)

chmod 754 script.sh     # Owner:rwx, Group:r-x, Others:r--
chmod u+x script.sh     # Add execute for owner
chmod go-w script.sh    # Remove write for group/others

chown alice:developers file.txt   # Change owner:group
chgrp developers file.txt          # Change group only
Remember: Directories need execute (x) to be traversable. Without it, you can't cd in, even if you have read permission.

6. System Monitoring and Performance

Processes

ps aux                   # Snapshot of all processes
top                      # Real‑time process view (q to quit)
htop                     # Nicer top (install it!)

kill 1234                # Gracefully terminate PID 1234 (SIGTERM)
kill -9 1234             # FORCE kill (SIGKILL) — last resort
pkill firefox            # Kill all firefox processes by name

Resource Usage

free -h                   # Memory usage (human‑readable)
df -h                     # Disk free space
du -sh /home/*            # Disk usage by user home

Logs

# Traditional logs
tail -f /var/log/syslog           # Ubuntu/Debian
tail -f /var/log/messages         # RHEL/CentOS
tail -f /var/log/secure           # Auth logs (RHEL)
tail -f /var/log/auth.log         # Auth logs (Debian)

# Modern systemd logs
journalctl -u ssh.service         # Logs for SSH service
journalctl -f                     # Follow logs (like tail -f)
journalctl --since "1 hour ago"   # Recent logs

7. Backup and Recovery

The 3‑2‑1 Rule

  • 3 copies of data
  • 2 different media types
  • 1 copy off‑site

Tar Commands

# Create backups
tar -cvf backup.tar /home/user          # No compression
tar -czvf backup.tar.gz /home/user      # gzip compression
tar -cjvf backup.tar.bz2 /home/user     # bzip2 compression

# Extract backups
tar -xzvf backup.tar.gz                  # Extract gzip
tar -xjvf backup.tar.bz2                 # Extract bzip2
tar -xvf backup.tar -C /restore/location # Extract to specific dir

Rsync — The Backup King

# Local sync
rsync -av /source/dir/ /backup/dir/      # Archive mode, verbose

# Remote over SSH
rsync -avz -e ssh /local/dir user@remote:/backup/

# Key options:
# -a : archive (preserve perms, recursive)
# -v : verbose
# -z : compress during transfer
# --delete : remove files in destination not in source

8. Basic Troubleshooting Methodology

🧠 Google the exact error message. 90% of problems are already solved by someone else.

  1. Identify the problem — Get specifics, not "it's broken"
  2. Establish theory of probable cause — Start simple (service stopped? disk full?)
  3. Test the theory — Try your fix
  4. Escalate/research — Google exact error messages, man pages
  5. Establish plan of action — Know what you'll do before doing it
  6. Implement and test — Fix it, verify it's fixed
  7. Document — Write it down for next time

Quick Checks

systemctl status service-name     # Is the service running?
df -h                              # Disk full?
journalctl -xe                     # Recent errors
ping google.com                    # Network connectivity?
ss -tulpn                          # What ports are listening?
